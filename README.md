# 🌦 Skye - Weather App (Streamlit)

A simple and interactive **Weather App** built using **Python and Streamlit**.
This app provides **real-time weather information** and a **5-day forecast** for any city using the OpenWeatherMap API.

---

## 🚀 Features

* 🌡️ Real-time temperature
* 💧 Humidity and pressure
* 🌥️ Weather condition with icons
* 📅 5-day weather forecast
* 🎨 Clean and responsive UI
* ⚡ Fast API-based data fetching

---

## 🛠️ Tech Stack

* Python
* Streamlit
* OpenWeatherMap API
* Requests library

## ⚙️ How It Works

* User enters a city name
* App fetches data using OpenWeatherMap API
* Displays current weather details
* Shows 5-day forecast in a card layout

## ▶️ How to Run

### 1️⃣ Install dependencies

```id="s6ym93"

```

### 2️⃣ Run the app

```id="yzckzo"

```

### 3️⃣ Open in browser

```id="x6c7q1"
http://localhost:8501
```

## 🔑 API Setup

1. Go to OpenWeatherMap
2. Generate your API key
3. Replace the API key in `app.py`:

```id="sz6snz"
API_KEY = "your_api_key_here"
```
